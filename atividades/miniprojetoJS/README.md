# 📝 Gerenciador de Tarefas - Geração Tech 3.0

Aplicação de lista de tarefas interativa desenvolvida para praticar manipulação do DOM e consumo de APIs REST com JavaScript assíncrono.

## ✨ Funcionalidades
- **CRUD Completo**: Adicionar, listar e excluir tarefas.
- **Busca em tempo real**: Filtro dinâmico por título.
- **Persistência**: Dados salvos em um backend simulado (JSON Server).
- **Interface Moderna**: Modal para criação e design responsivo.

## 🛠️ Tecnologias
- HTML5 / CSS3 / JavaScript (ES6)
- [JSON Server](https://github.com/typicode/json-server) (API fake)
- [Boxicons](https://boxicons.com/) (Ícones)

## 🚀 Como usar

1. **Instale as dependências:**
   "npm install"
2. **Inicie o servidor da API:**
    "npm run api"
3. **Acesse o projeto:**
    "Abra o arquivo index.html no seu navegador (ou via Live Server)".
